# Basic Arithmetic Calculator

Student: He Jiatao (2518040220)

## How I built it

1. I created `index.html` with two fields for numbers, four operation buttons, and a result area.
2. I added `styles.css` to style the background, inputs, buttons, and result.
3. In `script.js`, I used `getElementById` to find the fields and result area. I used `addEventListener` so each button runs the calculation for its operation.
4. I convert the entered text to numbers, check that both values are present and valid, and prevent division by zero. The answer or an error message appears in the result area.

## How to use it

Open `index.html` in a browser. Enter two numbers and click Add, Subtract, Multiply, or Divide. Decimal and negative numbers are supported.
